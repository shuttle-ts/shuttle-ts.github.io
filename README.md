## 廉价机场

选个廉价机场，注册并购买他们提供的代理服务。

- [三毛机场](https://gw-2.smjc2.com/#/register?code=mnwOqUgN)  
[官方防丢导航](https://三毛导航.com/)
- [一元机场](https://xn--4gq62f.com/#/register?code=iusP9RxU)  
质量较差，备用

购买完成后在主页复制出**订阅链接**，之后从下面任选一个客户端下载，在配置/订阅等地方导入即可使用。
